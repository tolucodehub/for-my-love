For My Love — Example Vite + React project
=========================================

This is a small personalized mini-site made for Annora by Toluwase.

How to run locally:
1. Install dependencies:
   npm install

2. Run dev server:
   npm run dev

3. Open the displayed local URL (usually http://localhost:5173)

Notes:
- Replace the placeholder photo in /public with your own image and update the <span> text instruction in src/App.jsx if needed.
- The messages are editable in src/App.jsx (MESSAGES array).
- Deploy to Vercel or Netlify by pushing to GitHub and connecting the repo.

Enjoy! 💙
